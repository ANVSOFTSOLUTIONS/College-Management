# Frontend

React.js and Vite application. Tailwind CSS can be added when the first feature screens are implemented.

Planned areas:

- `src/App.jsx`: initial application shell and API status check
- `src/main.jsx`: React entrypoint
- `src/index.css`: base visual system
- `src/features/`: dashboard and domain modules
- `src/lib/`: API client, auth, and shared utilities

Run `npm install` and `npm run dev` from this directory. Implementation continues in Phase 1 of `../docs/PROJECT_PLAN.md`.
